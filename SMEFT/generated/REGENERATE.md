The committed matrix elements were generated by MadGraph5_aMC@NLO 3.5.17
from SMEFTsim 3.0.2, using the `U35_MwScheme` model. They are genuine generated
tree amplitudes. Runtime evaluation requires a C++17 compiler and Python's
standard `ctypes`; it does not require MadGraph, FeynRules or a Fortran compiler.

Download and verify these archives, extract them into a disposable working
directory, and run from the repository root:

```bash
python SMEFT/generated/regenerate_backend.py \
  --mg5 /path/to/unpacked/mg5amcnlo \
  --smeftsim /path/to/unpacked/SMEFTsim
```

The script replaces `models/SMEFTsim_U35_MwScheme_UFO` in that disposable MG5
directory. The supplied source trees must be the pinned commits above; version
labels are also checked. Generation needs Python's `six` module and a C++
compiler. Source and runtime-card hashes are recorded in `provenance.json`.
Use `--destination /tmp/hb-regenerated` to compare a fresh export with the
committed files without replacing them.

The restriction starts from upstream `restrict_SMlimit_massless.dat`, retains
only `cHB=0.1`, and keeps `linearPropCorrections=0`. Nonzero `cHB` is necessary
at generation time so the restriction does not remove its vertices. The
runtime card resets `cHB=0`; the wrapper evaluates it at the requested values.
All external charged-lepton masses and Yukawa couplings vanish. The current
runtime API supports direct e/μ channels and rejects τ channels.

The actual generation commands are:

```text
import model SMEFTsim_U35_MwScheme_UFO-OHB
generate h > e- e+ mu- mu+ QCD=0 SMHLOOP=0 NP<=1
add process h > e- e+ e- e+ QCD=0 SMHLOOP=0 NP<=1
add process h > mu- mu+ mu- mu+ QCD=0 SMHLOOP=0 NP<=1
output standalone_cpp EXPORT_DIRECTORY -f
```

`NPprop` disappears when this restriction removes its vertices; writing
`NPprop=0` in those commands therefore causes MG5 to reject the command.
The restriction already sets these corrections to zero. `SMHLOOP=0` excludes
the effective SM loop-induced Hγγ/HZγ vertices. Full four-lepton final states
retain the cHB-induced ZZ, Zγ and γγ contributions, their interference, and
identical-lepton exchange. The five mixed-flavor and ten identical-flavor
diagrams contain at most one dimension-six vertex per amplitude. Squaring
that amplitude gives the SM term, SM–dimension-six interference, and the
dimension-six square. It does not supply dimension-eight interference or NLO
corrections. The Z width stays fixed at every coefficient value.

`vendor_generated.py` makes only these interface changes to the export:

- Rename the three `CPPProcess` classes so they can coexist in one library.
- Replace adaptive helicity pruning with a deterministic sum over all 16
  helicities. Earlier kinematics or coefficient values cannot disable a later
  helicity contribution. Generated wavefunctions, amplitudes, signs and
  symmetry factors remain unchanged.
- Remove informational parameter and SLHA opening messages.
- Reset the runtime card to `cHB=0`.

MG5 divides the identical-flavor squared matrix elements by four; that factor
cancels in the EFT/SM ratios. The wrapper samples cHB=0,+1,−1 at fixed
Λ=1000 GeV and returns the coefficients of `1+cHB*l+cHB²*q`. Negative `q`
is rejected except for cancellation error below its explicit numerical
tolerance, which is set to zero. No event weights or interference values are
clipped. `hb_matrix_elements` exposes direct evaluation at an arbitrary
coefficient for independent validation.

To compile the committed native sources directly:

```bash
g++ -std=c++17 -O2 -fPIC -shared -pthread \
  -ISMEFT/generated/src \
  SMEFT/native/hb_wrapper.cc SMEFT/generated/src/*.cc \
  -o /tmp/libhb.so
```

The wrapper includes the three process `.cc` files; do not compile those
separately. Avoid `-ffast-math`/`-Ofast`: finite-value checks are part of the
native API. Every exported function returns zero on success and a nonzero
status plus a bounded error message on failure. A mutex protects the generated
model singleton. See `../licenses/` for the upstream redistribution notices.
